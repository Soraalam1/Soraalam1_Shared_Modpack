Before using this mod, please read the following information...
--------------------
Version Compatibility

The texture hacks in this mod should be compatible with any software version.
--------------------
How to Use This Mod

Place the "ui" folder into the following directory on your Micro SD Card...

[SD Card]\atmosphere\contents\01006A800016E000\romfs\arc\

Next, you'll have to download the latest version of ARCropolis, and extract its contents over to the root of your Micro SD Card.

https://github.com/Raytwo/ARCropolis/releases/latest

Finally, load up Super Smash Bros. Ultimate, and you should be all set.

Note: The contents of this mod are not compatible with Ultimate Mod Manager, as they can't be compressed to a small enough size to be used with that method.
--------------------
Compressed or Decompressed?

All texture hack files are decompressed.
--------------------
Online Usage

Texture hacks are merely aesthetic, and shouldn't affect game play in any way. Still, I would avoid playing online while using mods.
